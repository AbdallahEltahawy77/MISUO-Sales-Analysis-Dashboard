# 📊 MISUO Sales & Logistics Dashboard

## 📌 Project Overview
This dashboard provides a detailed analysis of sales performance and logistics for **MISUO**. It tracks key metrics like total revenue, order status, and top-selling products to help in data-driven decision making.

## 🚀 Key Features & Insights
* **Sales KPIs:** Tracked Total Sales, Average Price, and Total Orders.
* **Logistics Tracking:** Monitored delivery status (Delivered vs. Canceled) to improve shipping efficiency.
* **Product Insights:** Identified the **Top-Selling Color**, helping in inventory management.
* **Platform Analysis:** Compared sales across different sales channels (Web, App, etc.).
* **Monthly Trends:** Visualized sales growth using an Area Chart for better forecasting.

## 🛠️ Skills Demonstrated
* **Data Transformation:** Using Power Query to clean and structure the sales data.
* **Data Modeling:** Creating relationships between sales, products, and dates.
* **DAX Measures:** Developed measures for average order value and delivery rates.
* **UI/UX Design:** Applied brand colors (MISUO Identity) for a professional look.
